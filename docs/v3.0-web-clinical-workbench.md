# v3.0 Web 临床工作台升级

## 1. 本版目标

把原先以聊天页为核心的前端升级为完整临床工作平台，新增统一工作台、待办通知、复核中心、质量中心、全局搜索、临床计算器和报告工作台。

## 2. 新增页面与入口

### 2.1 临床工作台

路径入口：顶部「工作台」标签。

聚合展示：

- 在管患者、待复核会诊、到期随访、绿道评估、已签署报告、AI 好评率
- 待复核会诊队列
- 到期随访队列
- 近期绿道评估
- 最近患者快捷入口
- 快速进入问诊、绿道、患者管理

后端接口：`GET /api/dashboard/summary`

### 2.2 医生复核中心

- 集中展示 `PENDING` 复核任务
- 查看专家共识、综合提案和关键风险
- 填写意见后驳回并重新会诊
- 批准后直接生成最终报告
- 处理结果实时刷新待办数量

### 2.3 质量与系统中心

聚合：

- DNT 中位数、4.5 小时窗内率、关键字段完整率
- 风险信号命中数
- AI 回答反馈总量、好评率
- 待复核数量
- Java 后端健康、在线用户、知识库文档/分块、缓存与持久化队列

### 2.4 全局搜索

快捷键：`Ctrl + K` / `Command + K`。

支持搜索：

- 当前医生负责的患者
- 当前医生的历史对话
- 医学资料与指南

结果支持直接跳转患者档案、对话或医生学习模块。

后端接口：`GET /api/search?q=`

### 2.5 通知中心

从工作台聚合数据生成待办通知：

- AI 会诊待复核
- 患者随访到期
- 支持未读状态、全部已读和跳转到对应业务页面

### 2.6 临床计算器

右侧抽屉提供：

- rt-PA 剂量计算
- 溶栓时间窗判断
- GCS
- mRS
- CHA₂DS₂-VASc
- HAS-BLED

结果可一键复制到病历或会诊输入中。

### 2.7 患者上下文侧栏

问诊页选中患者后，显示：

- 患者姓名与 AI 风险
- 既往病史
- 医生备注
- 最近 AI 意见
- 一键打开患者档案与纵向时间线

### 2.8 AI 报告工作台

针对每条 AI 回答可打开报告工作台：

- 编辑报告内容和标题
- 同时查看 AI 原始稿
- 保存草稿并自动增加版本
- 医生电子签名
- 导出 Markdown、Word、JSON
- 打印或另存 PDF

后端数据表：`clinical_report`（V6 迁移）

接口：

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/reports/by-talk/{talkId}` | 查询该对话的报告版本 |
| GET | `/api/reports/{reportId}` | 获取报告详情 |
| POST | `/api/reports` | 保存或更新报告草稿 |
| POST | `/api/reports/{reportId}/sign` | 医生签署报告 |

### 2.9 PWA 与移动端入口

- 增加 Web App Manifest、应用图标和 Service Worker。
- 支持在桌面或手机安装为独立应用，缓存静态资源；API 请求不使用离线缓存。

### 2.10 临床工具代理

后端将模型层的 18 个临床工具安全代理给 Web 前端：

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/tools/list` | 获取工具 schema |
| POST | `/api/tools/call` | 调用指定临床工具 |

## 3. 数据库迁移
