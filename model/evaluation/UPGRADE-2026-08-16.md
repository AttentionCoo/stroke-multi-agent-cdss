# 模型层升级总结(阶段3~7, 2026-08-16)

接续 `BASELINE-2026-08-15.md`(阶段0~2 已完成: 基线冻结/依赖卫生/检索层强化)。
本文件记录阶段3~7 的交付内容与验证结果。

## 阶段3 智能体演进(commit c1a1b09)

- **结构化输出**: intent / evidence_router / research_plan 三节点接入
  `llm.with_structured_output()`(Pydantic Schema, `app/agents/schemas.py`),
  Literal 硬校验 + 失败自动回退原有"流式生成+JSON解析"路径, 行为零风险。
- **HITL 人工复核**: 报告生成前可选医生审批(`human_review=true` 时 interrupt 挂起),
  新端点 `/model/resume`(approved/feedback), 驳回携意见反馈专家重新会诊,
  驳回达上限(默认2次, `HITL_MAX_REJECTS`)强制出报告保证终止。
- **检查点持久化**: `AsyncSqliteSaver`(volume `/app/data/checkpoints.sqlite`,
  在应用事件循环内创建), 普通线程结束后即清理, 仅待复核线程保留,
  启动期按 7 天 TTL 兜底清理。
- 验证: 容器内实测结构化输出(qwen-turbo)+interrupt/resume 往返 +
  完整 HITL 端到端(挂起→医生批准→报告→done status=completed)。

## 阶段4 多模型解耦(commit cb96f49)

- `app/config/models.yaml` + `ModelRouter`: 按角色路由(main/fast/turbo/consensus),
  同角色实例缓存; `MODEL_MAIN/FAST/TURBO/CONSENSUS` 环境变量覆盖,
  兼容旧 `CONSENSUS_MODEL`; 默认值与原实现完全一致。

## 阶段5 性能可靠性

- `request_timeout`(默认120s)/`max_retries`(默认3, 429/5xx 自动退避重试),
  provider 级默认 + role 级覆盖。
- 新端点 `/model/info`: 模型路由配置/检查点类型/知识库健康/运行时长/在途请求数。

## 阶段6 评测闭环

- `app/evaluation/gate.py`: BASELINE 硬门禁可执行化
  (Recall@3≥0.783 / MRR≥0.757 / NDCG@10≥0.763; 软门禁 Recall@10/faithfulness 仅告警),
  指标四舍五入到 3 位与基线对比。
- `evaluation/ragas_snapshot.json`: 30 题基线快照(机器可读), CI 每次执行门禁。
- `evaluation/offline_cases.jsonl`(6 题: 禁剂量/禁确诊语气/引用白名单) +
  `offline_predictions.jsonl`(冻结真实输出, 全过), `benchmark.py --gate` 门禁。
- CI(model job): 离线测试全集 + RAGAS 快照门禁 + 离线规则门禁, 见 `evaluation/README.md`。

## 阶段7 安全合规

- **错误脱敏**: `build_error_event` 不再向客户端暴露内部异常细节(错误码+通用提示)。
- **日志脱敏**: `mask_sensitive`(身份证/手机号/银行卡)应用于请求日志。
- **并发闸**: 单用户(默认2)/全局(默认8)在途请求上限, 超限 429(SSE 流外拒绝)。
- **输入约束**: question≤2万字符 / all_info≤10万 / 影像≤5张 / KB上传≤10个且单文件≤20MB。
- **CORS**: 默认关闭, `MODEL_CORS_ORIGINS` 按需放行。
